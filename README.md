# nexupira-open-places

A monthly extract of [Overture Maps](https://overturemaps.org/) Places for Taiwan, Japan, the United Kingdom and the United States.

Each release has one `<category>.ndjson.gz` file per category. `latest.json` lists the current release and the number of places per category.
