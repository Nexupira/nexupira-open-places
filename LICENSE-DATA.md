# Data licence and attribution

The data files of this repository's releases are a filtered extract of the **Overture Maps Foundation** Places theme (https://overturemaps.org/, https://docs.overturemaps.org/attribution/).

Overture states that the Places theme contains no OpenStreetMap data and carries no ODbL obligations. Each place lists the licence of its sources. In the extracts so far (Taiwan, Japan, United Kingdom, United States), every record falls under one or more of these licences:

| Licence | Sources (as listed by Overture) | Text in this repository |
|---|---|---|
| Community Data License Agreement – Permissive 2.0 (CDLA-Permissive-2.0) | Overture, Meta, Microsoft, BrightQuery, Uberall, PinMeTo, DAC, OpenTravel Alliance, Birdeye, RenderSEO, Overture signals | `LICENSE-CDLA-Permissive-2.0.txt` |
| Apache License 2.0 (Apache-2.0) | Foursquare | `LICENSE-Apache-2.0.txt`, `NOTICE` |
| Creative Commons Zero 1.0 (CC0-1.0) | AllThePlaces | `LICENSE-CC0-1.0.txt` |

## Changes made in this extract

Rows are filtered and only a few fields are kept (id, name, category, website, city, region, confidence). The data is regrouped into one file per market and category.
